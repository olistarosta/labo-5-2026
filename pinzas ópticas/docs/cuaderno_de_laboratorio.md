# **Práctica 4: Pinza Óptica**

## **Marco teórico**

Esta práctica permite observar y caracterizar el movimiento Browniano de partículas en suspensión así como manipularlas mediante una pinza óptica. En el capítulo 2.2 de la [tesis de grado de Augusto Kielbowicz](http://users.df.uba.ar/gpuentes/UBAThesis.pdf) hay una buena descripción de cómo estudiar el movimiento browniano usando el desplazamiento cuadrático medio.
